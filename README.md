This repository contains a RESTful API built with Node.js (ES6+), Express and MongoDB for tracking inter-provincial buses in Sri Lanka. The project includes an interactive dashboard, simulation datasets (JSON/CSV), an OpenAPI specification, and a test suite.

 Quick start

Prerequisites: Node.js (v16+ recommended), npm

```powershell
# clone
git clone https://github.com/Sewminikangara/NTC-BUS-TRACKER-COBSCCOMP4Y24.1P-010
cd ntc-bus-tracker

# install
npm install

# copy env template and edit .env
copy .env.example .env

# run in dev
npm run dev

# run tests
npm test
```

## What you'll find

- `src/` — app source (controllers, models, routes, middleware)
- `public/` — interactive dashboard (frontend)
- `docs/openapi.yaml` — OpenAPI 3.0 specification
- `exports/json/` and `exports/csv/` — simulation data
- `tests/` — Jest test suites

## API (selected endpoints)

Base URL: `https://web-production-5bd5.up.railway.app/api`

- Authentication
  - `POST /api/auth/register` — register
  - `POST /api/auth/login` — login (returns JWT)

- Routes
  - `GET /api/routes` — list (filter/sort/paginate)
  - `GET /api/routes/:id` — retrieve
  - `POST /api/routes` — create (admin)
  - `PUT /api/routes/:id` — update (admin)
  - `DELETE /api/routes/:id` — delete (admin)

- Buses
  - `GET /api/buses`
  - `GET /api/buses/:id`
  - `POST /api/buses` (admin)

- Trips
  - `GET /api/trips`

- Locations
  - `POST /api/locations` — create location update (operator)
  - `GET /api/locations/bus/:busId/latest` — latest location

Full API specification is available at `docs/openapi.yaml` and the live docs (if deployed) at `/api-docs`.

## Simulation data

The repository includes sample datasets used for demonstrations and tests:

- JSON: `exports/json/` (routes.json, buses.json, trips.json, locations.json)
- CSV: `exports/csv/`

Data is generated by `scripts/generateSimulationData.js` and reflects realistic Sri Lankan routes used in the coursework demonstration.

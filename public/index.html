Advanced API Features

1. Pagination Example

Navigate through large datasets efficiently using page and limit parameters.

GET /api/routes?page=2&limit=10

2. Filtering by Multiple Fields

Filter results using query parameters for precise data retrieval.

GET /api/buses?status=active&serviceType=luxury

3. Range Queries

Use operators like gte, gt, lte, lt for numeric comparisons.

GET /api/routes?distance[gte]=100&distance[lte]=200

4. Multi-field Sorting

Sort by multiple fields using comma separation. Use minus (-) for descending order.

GET /api/routes?sort=distance,-fare

5. Field Selection

Request only specific fields to reduce response payload size.

GET /api/routes?fields=routeNumber,name,origin,destination

6. Search Functionality

Search across multiple fields using regex pattern matching.

GET /api/routes?search=Colombo

HATEOAS Demonstration

Hypermedia Links

What is HATEOAS?

HATEOAS (Hypermedia as the Engine of Application State) is a REST constraint where the API provides hypermedia links in responses, allowing clients to dynamically discover available actions without hardcoding URLs.

Example: Get Single Route with Links

Response Structure with HATEOAS

Every API response includes:

  • self - Link to the current resource
  • collection - Link to the parent collection
  • related - Links to related resources
  • actions - Available CRUD operations (create, update, delete)
  • pagination - Next/previous page links (for collections)
